# Example clips

Both files are **synthetic** (generated by `src/core/synth.ts`), not real
speech - useful for trying "Load file..." without a microphone.

- `mandarin-tone2-reference.wav` - a clean Mandarin tone 2 (rising, Chao
  "35") contour, the same shape used by the "Tone 2 - rising" built-in
  reference chip.
- `mandarin-tone2-attempt-late-rise.wav` - a deliberately imperfect attempt:
  flat for the first 60% of the syllable, then a shallow rise. Load the
  first file as the reference and the second as your attempt to see the
  app flag "starts flat" / "rise is too shallow" - this is the exact pair
  used for the README's hero screenshot (similarity score 87).

Regenerate or make more pairs with:

```sh
npx tsx -e '
import { synthesizeFromContour } from "./src/core/synth.ts";
import { mandarinToneContour } from "./src/core/mandarinTones.ts";
// ... encode synthesizeFromContour(...) to WAV, see scripts/accuracy-report.ts
// for how the core is used outside the browser.
'
```
